# Simple Blog의 UI/UX Design Scheme

## 아이콘
- 아이콘은 Tabler Icons(`@tabler/icons-react`)를 기본으로 사용한다.
- 아이콘만 표시하는 버튼에는 `title`과 `aria-label`로 이름을 붙인다.
- 아이콘 크기는 주변 글자 크기에 맞추고, 색은 주변 글자 색을 따른다.

## Main Page
메인 페이지는 수직 방향으로 아래 영역으로 구성된다.
별도의 페이지 지정이 없는 루트(`/` 혹은 표시 없음)로 지정된 경우 가장 최근 글을 본문 내용으로 표시한다.

### Header
'Dreaming for the Future' 라는 표제어를 표시하고, 바로 이어 '영원한 개발자를 향해'라는 부제어 문구를 표시한다.
Dreaming for the Future: 2.5em
영원한 개발자를 향해: 1.2em
영역 높이: 6em
텍스트는 영역의 중간에 배치한다.
표제어를 링크를 설정하고, 홈 (`/`)으로 이동한다.
부제어를 링크를 설정하고, `/page/about` 으로 이동한다.
링크 설정 효과는 없도록 하고, 포인터만 기본 링크 포인터 형식이 되도록 한다.


### Search and Navigation
검색용 입력 박스와 페이지 목록이 한줄로 표시한다.
검색용 입력 박스 크기: 10em
입력박스 뒤에 페이지 목록을 표시한다.
영역 높이: 1.5em
텍스트는 영역의 중간에 배치한다.

### Contents
나머지 공간을 제외하고 전체 공간을 모두 컨텐츠 공간으로 사용한다.
배경색은 종이 질감을 갖는 흰색 계열을 적용한다.
컨텐츠 영역은 폭은 스크롤이 나오지 않도록 하고, 컨텐츠가 컨텐츠 화면 높이를 초과하는 경우에만 스크롤을 표시한다.
좌우 2rem 수준의 공백을 반영한다.
컨텐츠 요소들은 좌측 align을 기본적으로 적용한다.
컨텐츠 영역은 다음 2가지 영역을 수직 분할한다.
-. 우측은 70em 크기의 정보 영역이 된다.
-. 나머지 영역은 본문 내용 표시 영역으로 사용한다.

#### 우측 정보 영역
최근 작성 글 목록을 표시하며 총 7개를 표시한다.
목록에서 글 제목만 표시한다. 제목을 선택하면 글의 본문을 조회할 수 있도록 한다.
제목이 화면을 넘치게 되면 `...` (ellipse) 방식으로 표시해 줄 바꿈이 발생하지 않도록 한다.
목록 마지막에는 `전체 목록`을 표시하고 전체 글 목록을 조회할 수 있도록 링크를 설정한다.
전체 목록 우측으로 1em 공간을 두고, Feed 로고를 노출하고 로고를 클릭하면 Feed 링크를 클립보드에 복사한다.
새 문서 아이콘(Tabler `IconFilePlus`)과 `새로운 생각` 이라는 링크를 만들고, 글 작성 영역으로 링크를 설정한다.

#### 본문 내용 표시
- 제목은 h1 유형을 적용해 표시한다.
- 작성일은 시각적으로 눈에 표시되지 않는 컬러를 적용하고, 본문 글 크기보다 작게 표시한다.
- 작성일 옆에 복사 아이콘과 함께 공유하기 링크를 둔다. 링크를 설정하면 공유 링크를 클립 보드에 복사한다.
- 해당 버튼 뒤에 링크드인 아이콘을 배치하고, 링크드인 작성 페이지가 팝업되도록 한다.
- 만약 인증된 사용자라면 작성일 옆에 `편집하기` 링크를 노출하고, 클릭하면 기존 컨텐츠가 글 작성 영역에 표시되고 편집되도록 한다.
- 본문은 읽기에 편한 폰트 색을 적용한다.

### 글 목록
전체 목록을 표시하거나 검색 결과로 선택된 글 목록을 노출한다.
검색된 결과를 표시하는 경우에는 먼저 검색 조건을 h2 스타일로 표시하고 항상 검색 조건이 표시되도록 한다.
글 목록은 최대 20개까지 표시하고, `PREV` 및 `NEXT` 방식으로 탐색하고 페이지 기능을 제공하지는 않는다.
본문은 본문 조회 API를 사용하고, 시간이 걸릴 수 있으니 Waiting 표시를 반영한다.
목록에는 글 제목, 작성일시, 게시 일시(Publish date)를 표시한다. 
세부 글에 대한 링크는 제목에 설정하고, hover 효과로 underline을 꼭 설정한다.
제목을 클릭하면 본문 내용을 표시하도록 Navigation 한다.

### 글 작성
컨텐츠 영역 전체를 글 쓰기 공간으로 사용한다.
글 제목, Slug, 본문, 해시태크를 입력할 수 있는 공간을 수직 배열한다.
제목, Slug, 해시태그는 한줄로 처리하고 본문이 전체 공간을 채운다.
각 영역 요소는 1rem으로 다음 항목간 여백을 설정한다.
본문 편집은 MDX Editor를 사용한다.
제목 줄 옆에 저장, 공개, 삭제 버튼을 글자 없이 아이콘으로 제공한다. 저장은 `IconDeviceFloppy`, 공개는 `IconWorldUpload`(공개된 후에는 `IconWorldCheck`), 삭제는 `IconTrash`를 사용한다.
해시태그 라인은 가장 마지막 줄에 표시한다.

### Footer
Copyright에 대한 기본적인 사항만을 표시한다.
한줄로만 표시한다.
높이: 2em
텍스트는 영역의 중간에 배치한다.

## 서재 공간 (Bookshelf)
컨텐츠 영역 전체를 활용해 책과 읽을 꺼리들에 대한 정보를 노출한다.
가장 앞에는 전체를 포함한 연도별 필터를 콤보박스리스트 형태로 제공한다. 기본은 All. 
연도 필터 우측에 2rem 정도 공간을 벌려`새로운 책`이라는 등록 기능을 제공한다.
전체 책 목록은 수직 2 단으로 나뉘어서 전체 책 목록을 노출한다.
- 노출 순서는 가장 최근 책을 먼저 노출한다.

### 개별 책 정보 
책의 썸네일 정보 우측에 책 이름과 기본 설명, 등록 일자를 표시한다.
- 썸네일 크기는 높이가 5em가 되도록 하고 폭은 비례해 맞춘다.
- 썸네일을 클릭하면 최초 등록한 판매처의 웹 페이지를 별도 탭으로 볼 수 있도록 해준다.
- 책 이름은 1.5em에 볼드 표시한다.
- 기본 설명과 등록 일자는 이탤릭으로 표시한다.
- 리뷰 slug가 존재하면 `리뷰 보기` 링크를 노출하고, 리뷰가 없다면 `리뷰 적기` 링크를 아이콘과 함께 나타낸다.
썸네일 하단에 읽기 시작한 날짜와 완료, 그리고 기간을 `N 개월` 혹은 `N 주` 방식으로 이탤릭으로 표시한다.
- 책에 대한 인사이트가 있다면 200자 이내로 표시하고 넘으면 ellipse 표시한다.
- 아직 읽지 않은 책이라면 `체크인하기`를 링크를 아이콘과 함께 노출한다.
리뷰 적기를 클릭하면 책 제목을 바탕으로 `review-about-` 이라는 prefix를 붙혀 slug를 제시하고, 필요하면 수정할 수 있도록 한다.

#### 체크인하기
날짜 및 완료 여부를 한 라인에 모두 표시한다.
- 읽기 시작한 날짜와 다 읽었다라면 완료 여부를 체크할 수 있도록 한다.
- 이미 완료 날짜가 있는 경우에는 체크 표시해주고, 완료일을 표시한다.
- 시작 날짜, 완료 날짜, 완료 체크, 체크인 시작 버튼 순서로 노출한다.
- 체크인 시작 버튼을 누르면 책 읽기가 시작되고, 시작일이 오늘 날짜로 설정된다.
- 이미 체크인이 시작된 경우, '체크인 저장'이라는 멘트를 노출하고, 입력된 시작 및 종료일을 변경한다.
만약 썸네일이 설정되지 않았다면 썸네일 URL을 입력받을 필드와 버튼을 노출하고 저장한다.
인사이트 항목은 자유롭게 적을 수 있도록 하고, 최소폭 50em (모바일은 화면 범위 내), 최소높이 15em이 되도록한다.
인사이트 등록을 누르면 인사이트 정보를 저장한다.
삭제 버튼을 누르면 등록된 책 정보를 삭제한다.
삭제 버튼은 최좌측, 인사이트, 닫기 버튼은 우측에 순서대로 배치한다.

### 책 정보 등록(새로운 책)
책 상세 정보 URL을 입력받는다.
- 해당 URL을 통해 썸네일 이미지, 제목, 저자, 소개글 정보를 가져온다.
- 저자와 소개글은 편집할 수 있도록 한다.
- 만약 썸네일이 없다면 없다는 아이콘을 큼지막하게 사용.
확인을 누르면 정보를 등록한다.
