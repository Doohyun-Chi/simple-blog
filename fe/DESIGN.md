# Simple Blog의 UI/UX Design Scheme

## Main Page
메인 페이지는 수직 방향으로 아래 영역으로 구성된다.

### Header
'Dreaming for the Future' 라는 표제어를 표시하고, 바로 이어 '영원한 개발자를 향해'라는 문구를 표시한다.
Dreaming for the Future: 2.5em
영원한 개발자를 향해: 1.5em
영역 높이: 6em
텍스트는 영역의 중간에 배치한다.

### Search and Navigation
검색용 입력 박스와 페이지 목록이 한줄로 표시한다.
검색용 입력 박스 크기: 10em
입력박스 뒤에 페이지 목록을 표시한다.
영역 높이: 1.5em
텍스트는 영역의 중간에 배치한다.

### Contents
나머지 공간을 제외하고 전체 공간을 모두 컨텐츠 공간으로 사용한다.
배경색은 종이 질감을 갖는 흰색 계열을 적용한다.

### Footer
Copyright에 대한 기본적인 사항만을 표시한다.
한줄로만 표시한다.
높이: 2em
텍스트는 영역의 중간에 배치한다.
