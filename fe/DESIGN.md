# Simple Blog의 UI/UX Design Scheme

## 아이콘
- 아이콘은 Tabler Icons(`@tabler/icons-react`)를 기본으로 사용한다.
- 아이콘만 표시하는 버튼에는 `title`과 `aria-label`로 이름을 붙인다.
- 아이콘 크기는 주변 글자 크기에 맞추고, 색은 주변 글자 색을 따른다.

## Main Page
메인 페이지는 수직 방향으로 아래 영역으로 구성된다.
별도의 페이지 지정이 없는 루트(`/` 혹은 표시 없음)로 지정된 경우 가장 최근 글을 본문 내용으로 표시한다.

### Header
'Dreaming for the Future' 라는 표제어를 표시하고, 바로 이어 '영원한 개발자를 향해'라는 부제어 문구를 표시한다.
표제어(main theme): Dreaming for the Future: 2.5em
부제어(sub theme): 영원한 개발자를 향해: 1.2em
영역 높이: 6em
텍스트는 영역의 중간에 배치한다.
표제어를 링크를 설정하고, 홈 (`/`)으로 이동한다.
부제어를 링크를 설정하고, 사용자 소개 페이지(`/post/{about slug}`)로 이동한다.
링크 설정 효과는 없도록 하고, 포인터만 기본 링크 포인터 형식이 되도록 한다.


### Search and Navigation
검색용 입력 박스와 네비게이션 목록이 한줄로 표시한다.
검색용 입력 박스 크기: 10em
입력박스 뒤에 1rem 공간을 벌이고, 네비게이션 항목을 표시한다.
영역 높이: 1.5em
모바일에서는 검색 옆에 More 아이콘과 텍스트를 노출하고 클릭하면 네비게이션 항목을 노출한다.


#### Navigation
다음의 항목을 노출한다.
- about 항목의 display text, 링크는 `/post/{about slug}`
- working 항목의 display text, 링크는 `/post/{working slug}`
- 책갈피, 책갈피 관리를 위해 제공되고 `/bookmark` 로 링크한다.
- 내서재
- 사용자 정보: 로그인 혹은 로그인이 되어있다면 사용자 이메일.
사용자 정보 영역은 충분한 공간이 확보된 상황(예를 들어 PC 혹은 테블릿)에서는 화면 우측에 1em padding을 주고 배치한다.
로그인된 사용자인 경우 클릭하면 `/user` 로 링크해 사용자 정보 조회 및 정보를 갱신할 수 있도록 한다.
로그인되지 않은 경우에는, 사용자 인증을 한다.
기존에 등록되지 않은 첫 사용자 인증이라면 사용자 정보 페이지로 유도한다.
각 항목은 1rem 정도로 여유 공간을 부여한다.
로그인되지 않은 상태에서는 about은 `/post/about`, working은 `/post/my-working-places`로 라우팅한다.
로그인되지 않은 상태에서는 사용자 설정을 조회하지 않고 기본값을 그대로 노출한다.
- 표제어: Dreaming for the Future
- 부제어: 영원한 개발자를 향해
- about 항목의 display text: 나의 꿈
- working 항목의 display text: 제가 일하는 곳은?

### Contents
나머지 공간을 제외하고 전체 공간을 모두 컨텐츠 공간으로 사용한다.
배경색은 종이 질감을 갖는 흰색 계열을 적용한다.
컨텐츠 영역은 폭은 스크롤이 나오지 않도록 하고, 컨텐츠가 컨텐츠 화면 높이를 초과하는 경우에만 스크롤을 표시한다.
좌우 2rem 수준의 공백을 반영한다.
컨텐츠 요소들은 좌측 align을 기본적으로 적용한다.
컨텐츠 영역은 다음 2가지 영역을 수직 분할한다.
-. 우측은 70em 크기의 정보 영역이 된다.
-. 나머지 영역은 본문 내용 표시 영역으로 사용한다.

#### 우측 정보 영역
우측 상단은 탭 방식으로 `최근 글`과 `최근 책갈피` 탭을 둔다.
탭 선택에 따라 글과 책갈피 내용을 따로 보여준다.
높이는 제목 7개가 표시될 수 있는 고정값을 적용한다.

#### 최근 글
- 최근 작성 글 목록을 표시하며 총 7개를 표시한다.
- 목록에서 글 제목만 표시한다. 제목을 선택하면 글의 본문을 조회할 수 있도록 한다.
- 제목이 화면을 넘치게 되면 `...` (ellipse) 방식으로 표시해 줄 바꿈이 발생하지 않도록 한다.

#### 책갈피
- 책갈피(Bookmark)된 목록을 총 7개 표시한다.
- 사용자 책갈피 항목 중 order desc 방식으로 표시한다.
- 목록이 없다면 중앙 정렬 방식으로 아직 항목이 없다는 멘트를 표시한다.
- 글과 동일한 방식으로 노출하고, 링크를 누르면 해당 글로 이동한다.

목록 마지막에는 `전체 글 목록`을 표시하고 전체 글 목록을 조회할 수 있도록 링크를 설정한다.
전체 목록 우측으로 1em 공간을 두고, Feed 로고를 노출하고 로고를 클릭하면 Feed 링크를 클립보드에 복사한다.
새 문서 아이콘(Tabler `IconFilePlus`)과 `새로운 생각` 이라는 링크를 만들고, 글 작성 영역으로 링크를 설정한다.

#### 본문 내용 표시
제목은 h1 유형을 적용해 표시한다.
제목 하단에 아래 정보를 표시한다.
- 책갈피 여부를 별모양 아이콘으로 표시한다. 아이콘을 선택하면 사용자의 책갈피에 추가되고, 이미 추가된 상태에서 클릭하면 삭제한다. 시각적으로 잘 표시되도록 한다.
- 작성자 이름(nick name)을 표시한다. 설정하지 않은 상태면 표시하지 않는다.
- 작성일은 시각적으로 눈에 표시되지 않는 컬러를 적용하고, 본문 글 크기보다 작게 표시한다.
- 작성일 옆에 복사 아이콘과 함께 공유하기 링크를 둔다. 링크를 설정하면 공유 링크를 클립 보드에 복사한다.
- 해당 버튼 뒤에 링크드인 아이콘을 배치하고, 링크드인 작성 페이지가 팝업되도록 한다.
- 만약 인증된 사용자라면 작성일 옆에 `편집하기` 링크를 노출하고, 클릭하면 기존 컨텐츠가 글 작성 영역에 표시되고 편집되도록 한다.
본문은 읽기에 편한 폰트 색을 적용한다.

### 글 목록
전체 목록을 표시하거나 검색 결과로 선택된 글 목록을 노출한다.
상단에는 표시 방식에 따라 `글 목록` 혹은 `검색 목록`을 표시하고, 같은 라인 화면 우측에 표시 방식 선택하도록 한다.
- 표시 방식을 목록으로 할지 카드 방식으로 할지를 아이콘으로 2개로 모두 표시하고 선택된 항목을 하이라이팅한다.
- 기본 표시 방식은 목록형이다.
- 카드 형은 한 라인에 2개 글을 표시한다.
- 검색된 결과를 표시하는 경우에는 먼저 검색 조건을 h2 스타일로 표시하고 항상 검색 조건이 표시되도록 한다.
글 목록은 최대 20개까지 표시한다.
- `PREV` 및 `NEXT` 방식으로 탐색하고 페이지 기능을 제공하지는 않는다.
- Prev, Next 옆에는 아이콘을 제공하고 폰트 크기는 1.5em 수준에서 잘 보이도록 표시한다.
- 처음이면 Prev를 표시하지 않고, 이후에 포스트가 더 없다면 Next를 표시하지 않는다.
본문은 본문 조회 API를 사용하고, 시간이 걸릴 수 있으니 Waiting 표시를 반영한다.
목록에는 글 제목, 작성일시, 게시 일시(Publish date)를 표시한다. 
세부 글에 대한 링크는 제목에 설정하고, hover 효과로 underline을 꼭 설정한다.
제목을 클릭하면 본문 내용을 표시하도록 Navigation 한다.

### 글 작성
컨텐츠 영역 전체를 글 쓰기 공간으로 사용한다.
글 제목, Slug, 본문, 해시태크를 입력할 수 있는 공간을 수직 배열한다.
제목, Slug, 해시태그는 한줄로 처리하고 본문이 전체 공간을 채운다.
각 영역 요소는 1rem으로 다음 항목간 여백을 설정한다.
본문 편집은 MDX Editor를 사용한다.
제목 줄 옆에 저장, 공개, 삭제 버튼을 글자 없이 아이콘으로 제공한다. 저장은 `IconDeviceFloppy`, 공개는 `IconWorldUpload`(공개된 후에는 `IconWorldCheck`), 삭제는 `IconTrash`를 사용한다.
해시태그 라인은 가장 마지막 줄에 표시한다.

### Footer
Copyright에 대한 기본적인 사항만을 표시한다.
한줄로만 표시한다.
높이: 2em
텍스트는 영역의 중간에 배치한다.

## 책갈피 관리
사용자가 북마크한 Post의 내역들을 관리한다.
화면은 수직으로 고정 북마크와 이외 북마크를 나눠 표시한다.
- 고정 북마크는 order 값이 0 이상인 항목이다.
- 고정 북마크 항목의 우측에는 순서 조정을 위한 핸들 아이콘과 고정 제거(order = 0) 아이콘을 제공한다.
- 이외 북마크에는 고정하기를 위한 아이콘을 제공한다.
- 고정하거나 고정을 해제하면 항목의 이동될 항목의 가장 위쪽에 반영시킨다.

사용자의 전체 북마크 내역들을 모두 표시한다.
- 책갈피 이름으로 변경할 수 있도록 Input Box로 표시한다. 최소 20em 이상에서 입력할 수 있도록.
- Post slug, 길 수 있으니 화면이 넘치면 ellipse 처리한다. Slug를 클릭하면 해당 포스트를 별도 탭으로 보여준다.
- Slug 복사를 위한 복사 아이콘
- 책갈피 삭제 아이콘

이름 변경이나 삭제는 직시 반영되고, 유의 사항을 관리 페이제 상단(페이지 제목 하단)에 작게 보여준다.
- 이름이 변경되는 경우 변경 시간을 현재 시간으로 설정한다.
순서 편집이 완료되면 `노출 순서 저장` 버튼으로 일괄 반영한다.
- 변경되는 정보는 책갈피 이름과 고정 여부 및 순서(order) 값이 반영된다.
- 변경 시간은 따로 업데이트 하지 않는다.


## 서재 공간 (Bookshelf)
컨텐츠 영역 전체를 활용해 책과 읽을 꺼리들에 대한 정보를 노출한다.
가장 앞에는 전체를 포함한 연도별 필터를 콤보박스리스트 형태로 제공한다. 기본은 All. 
연도 필터 우측에 2rem 정도 공간을 벌려`새로운 책`이라는 등록 기능을 제공한다.
전체 책 목록은 수직 2 단으로 나뉘어서 전체 책 목록을 노출한다.
- 노출 순서는 가장 최근 책을 먼저 노출한다.

### 개별 책 정보 
책의 썸네일 정보 우측에 책 이름과 기본 설명, 등록 일자를 표시한다.
- 썸네일 크기는 높이가 9em가 되도록 하고 폭은 비례해 맞춘다.
- 썸네일을 클릭하면 최초 등록한 판매처의 웹 페이지를 별도 탭으로 볼 수 있도록 해준다.
- 책 이름은 1.1em에 볼드 표시하고, 최초 등록한 판매처의 웹 페이지로 가는 링크(별도 탭)를 설정한다.
- 인증된 사용자라면 책 이름 옆에 작은 수정 아이콘(`IconPencil`)을 노출한다. 클릭하면 `책 수정` 창이 열린다.
- 기본 설명과 등록 일자는 이탤릭으로 표시한다.
- 리뷰 slug가 존재하면 `리뷰 보기` 링크를 노출하고, 리뷰가 없다면 `리뷰 적기` 링크를 아이콘과 함께 나타낸다.
썸네일 하단에 읽기 시작한 날짜와 완료, 그리고 기간을 `N 개월` 혹은 `N 주` 방식으로 이탤릭으로 표시한다.
- 책에 대한 인사이트가 있다면 200자 이내로 표시하고 넘으면 ellipse 표시한다.
- 아직 읽지 않은 책이라면 `체크인하기`를 링크를 아이콘과 함께 노출한다.
리뷰 적기를 클릭하면 책 제목을 바탕으로 `review-about-` 이라는 prefix를 붙혀 slug를 제시하고, 필요하면 수정할 수 있도록 한다.

#### 체크인하기
날짜 및 완료 여부를 한 라인에 모두 표시한다.
- 읽기 시작한 날짜와 다 읽었다라면 완료 여부를 체크할 수 있도록 한다.
- 이미 완료 날짜가 있는 경우에는 체크 표시해주고, 완료일을 표시한다.
- 시작 날짜, 완료 날짜, 완료 체크, 체크인 시작 버튼 순서로 노출한다.
- 체크인 시작 버튼을 누르면 책 읽기가 시작되고, 시작일이 오늘 날짜로 설정된다.
- 이미 체크인이 시작된 경우, '체크인 저장'이라는 멘트를 노출하고, 입력된 시작 및 종료일을 변경한다.
만약 썸네일이 설정되지 않았다면 썸네일 URL을 입력받을 필드와 버튼을 노출하고 저장한다.
인사이트 항목은 자유롭게 적을 수 있도록 하고, 최소폭 50em (모바일은 화면 범위 내), 최소높이 15em이 되도록한다.
인사이트 등록을 누르면 인사이트 정보를 저장한다.
체크인하기 창에는 삭제 버튼을 두지 않는다. 인사이트 등록, 닫기 버튼을 우측에 순서대로 배치한다.

### 책 정보 등록(새로운 책)
책 상세 정보 URL을 입력받는다.
- 해당 URL을 통해 썸네일 이미지, 제목, 저자, 소개글 정보를 가져온다.
- 저자와 소개글은 편집할 수 있도록 한다.
- 만약 썸네일이 없다면 없다는 아이콘을 큼지막하게 사용.
확인을 누르면 정보를 등록한다.

### 책 수정
책 이름 옆의 수정 아이콘을 누르면 `책 정보 등록(새로운 책)` 창을 그대로 재사용해 `책 수정` 창을 연다.
- 등록된 책 상세 정보 URL, 썸네일, 제목, 저자, 소개글이 처음부터 채워져 있고, 모두 편집할 수 있다. 썸네일은 이미지와 함께 URL 필드로 수정한다.
- `정보 가져오기`로 판매처 페이지의 정보를 다시 가져올 수도 있다.
- 확인을 누르면 수정한 정보를 저장한다.
- 삭제 버튼을 누르면 확인을 거쳐 등록된 책 정보를 삭제한다. 삭제 버튼은 최좌측에, 취소, 확인 버튼은 우측에 배치한다.

## 개인화
사용자가 상단의 이메일을 누르면 개인화 설정 페이지를 노출한다.

### 개인화 화면
편집 영역을 사용해 해당 정보를 조회 및 업데이트하고 완료되면 '변경' 혹은 '돌아가기' 버튼을 클릭하면 이전 화면으로 돌아간다.
변경 가능한 항목은 아래와 같다.
- 닉네임: 블로그에서 사용할 사용자의 닉네임을 설정한다.
- 표제어: 표제어를 입력받는다.
- 부제어: 부제어를 입력받는다.
- 개인 설명 페이지(about slug): 설명 입력과 about 링크를 통해 노출될 페이지의 슬러그를 한 줄로 입력받는다.
- 이력 설명 페이지(workings slug): 설명 입력과 개인 이력 링크를 통해 노출될 페이지의 슬러그를 한 줄로 입력받는다.
MCP 조회키는 항목을 Read Only로 조회할 수 있고, 클립보드 카피와 필요한 경우 Revoke할 수 있는 기능을 제공한다.
Revoke된 키는 서버에서 자동 업데이트하고 별도로 저장할 필요는 없다.
로그아웃 버튼을 최좌측에 두고, 변경과 돌아가기 버튼은 우측에 배치한다. 로그아웃하면 세션을 종료하고 홈(`/`)으로 이동한다.
